## 🛠️ How to Use

1. **Open** the app in your browser
2. **Drop files** onto the player or click **"Choose files"**
3. **Click any track** in the playlist to start playback
4. **Adjust EQ** sliders for your preferred sound profile
5. **Search** your playlist using the search bar

---

## 🎛️ EQ Bands

| Frequency | Range | Default |
|-----------|-------|---------|
| 60 Hz | Sub-bass | 0 dB |
| 170 Hz | Bass | 0 dB |
| 350 Hz | Low-mid | 0 dB |
| 1000 Hz | Mid | 0 dB |
| 3500 Hz | High-mid | 0 dB |

---

## 🏗️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Animations, transitions, glassmorphism UI
- **Vanilla JavaScript** — Audio API, drag & drop, EQ via Web Audio API
- **Web Audio API** — Real-time EQ processing

---

## 📦 Installation

No installation required. It runs entirely in the browser.

```bash
# Clone the repo
git clone https://github.com/Ab40D/SE7ENX-Player-Premium-Local-Audio-Experience.git

# Open index.html in your browser
open index.html
```

---

## 🔒 Privacy

Se7enX Player is **100% offline**. No files are uploaded, no analytics are collected, and no network requests are made. Your music stays on your device.
